# WARP Unblock для Android

Клиент для Android 7.0 и новее. Выбранные домены идут через Cloudflare WARP, остальной трафик по умолчанию — напрямую. Root не требуется.

## Первый запуск

1. Установите APK и откройте приложение.
2. Отключите другой VPN, если он работает.
3. Нажмите **Подключить** и подтвердите системный запрос VPN.
4. Приложение зарегистрирует аккаунт WARP и проверит соединение.
5. Если WARP не отвечает, откройте **Профили → Подобрать автоматически**, дождитесь результата и подключитесь снова.

Быстрый автоподбор останавливается на первом рабочем профиле. **Сравнить все и выбрать лучший** проверяет весь каталог и учитывает успешность и задержку. На Android доступно 11 профилей.

Ожидание WARP — **до 5 секунд на профиль**, суммарно на запросы и повторы. Пауза между профилями убрана. Первая регистрация аккаунта выполняется отдельно и может занять больше времени.

## Что проверено

На телефоне вручную проверены базовые сценарии: регистрация WARP с обходом DPI через ByeDPI, автоподбор, подключение, голос Discord и работа обычного интернета. Это проверка конкретного устройства и подключения, а не всех операторов и оболочек.

Для v0.3.1 прошли 5 unit-тестов, сборки двух APK и Android Lint. Новые настройки — выбор приложений, автозапуск, Always-on, камера QR и отправка журнала — реализованы, но ещё требуют практической проверки на телефонах. Длительная работа, переключение сетей и игровой голос отдельно не проверены.

## Если не проходит регистрация WARP

Приложение сначала пробует регистрацию напрямую, затем через локальный ByeDPI. Он используется только для регистрации аккаунта. Если оператор всё равно блокирует API Cloudflare, можно импортировать профиль с компьютера:

- **Файл:** передайте `wgcf-profile.conf` из Windows-версии и выберите **Профили → Импортировать профиль**.
- **QR:** в Windows откройте **Настройки → Дополнительно → QR для телефона**, затем в Android — **Профили → Импортировать QR**.

Профиль содержит приватный ключ. Не используйте один ключ одновременно на компьютере и телефоне; для каждого устройства предпочтителен отдельный аккаунт.

## Маршрутизация и домены

YouTube, Discord, Telegram, AI-сервисы и остальные домены из правил обхода идут через WARP. В Android Opera не используется. Для доменов без правила действует DIRECT. В конфигурации также есть блокировка рекламы и QUIC.

В **Настройки → Домены** можно редактировать списки «В обход через WARP» и «Напрямую». Отключите соединение, сохраните списки и подключитесь заново. DIRECT имеет приоритет над доменными правилами обхода.

```text
# Только этот домен
example.com

# Домен и все его поддомены
+.example.org
```

Один домен на строку. URL, IP-адреса и строки правил не подходят; международные домены записываются в punycode. [Общий формат списков Windows и Android](../docs/DOMAIN-LISTS.md).

## Выбор приложений и автоподключение

В **Настройки → Приложения в VPN** есть три режима: все, только выбранные или кроме выбранных. Показываются приложения с иконкой запуска. Доменные правила действуют внутри выбранных приложений; изменения применяются при следующем подключении.

Можно включить подключение при открытии приложения и после загрузки телефона. Первый запуск и выдача VPN-разрешения выполняются вручную. На некоторых оболочках потребуется разрешить автозапуск и отключить экономию батареи для приложения.

Через **Системные настройки VPN** можно включить Always-on («Постоянная VPN») и системную блокировку соединений без VPN. При такой блокировке приложения, исключённые из VPN, могут потерять сеть. Эти режимы зависят от системы и требуют проверки на вашем устройстве.

В шторку можно добавить плитку **WARP** для подключения и отключения.

## Обновления и журнал

При запуске приложение проверяет релизы (выключается в настройках). Если вышла новая версия, появится окно с описанием и кнопкой **Обновить**: приложение скачает APK для архитектуры телефона, сверит SHA-256 и откроет системный установщик. В первый раз Android попросит разрешить установку из WARP Unblock. Подпись сохранена, удалять приложение не нужно. Перейти с версий до этой (v0.3.1 и раньше) нужно вручную: скачайте APK из релизов.

Если что-то не работает, откройте **Журнал → Поделиться журналом**. Укажите версию, профиль, модель телефона, Android и оператора в [issue](https://github.com/kwlnd/warp-unblock/issues/new). Журнал может содержать домены и IP; профиль WARP и QR с приватным ключом публиковать нельзя.

## Для разработки

Исходники находятся в папке `android/` ветки `main`. Kotlin + Compose, VpnService, mihomo, hev-socks5-tunnel; для регистрации используется ByeDPI. Нативные библиотеки и релизные APK собирает [GitHub Actions](https://github.com/kwlnd/warp-unblock/actions/workflows/android.yml).

Для локальной сборки нужны JDK 17, Gradle 8.9, Android SDK 34 и нативные библиотеки в `android/app/src/main/jniLibs/<abi>/`:

```shell
gradle -p android testDebugUnitTest assembleRelease lintRelease
```

APK подписываются ключом проекта из `android/hobby-signing.jks`, чтобы обновления ставились поверх. Этот ключ не предназначен для публикации в магазине.
