# WARP Unblock для Android

Для Android 7.0 и новее, root не нужен. Заблокированные сервисы идут через Cloudflare WARP, остальной интернет — напрямую.

**[Скачать последнюю версию](https://github.com/kwlnd/warp-unblock/releases/latest)**

| Файл | Для чего |
| --- | --- |
| `WarpUnblock-android-…-arm64-v8a.apk` | Почти все телефоны |
| `WarpUnblock-android-…-universal.apk` | ТВ-приставки, 32-битные системы или если не уверены |

## Первый запуск

1. Установите APK и откройте приложение.
2. Если включён другой VPN (особенно FlClash и другие клиенты на ядре Clash), выключите его.
3. Нажмите кнопку на главном экране и разрешите VPN.
4. Приложение само создаст аккаунт WARP и проверит соединение.
5. После первого подключения разрешите **работу в фоне**. Без этого Xiaomi, Samsung, Huawei и другие оболочки могут закрыть VPN, когда гаснет экран.

Если WARP не отвечает — **Профили → Подобрать**.

Цвет значка в шапке и в уведомлении показывает состояние: серый — выключено, жёлтый — подключение, оранжевый — работает, красный — нет связи.

## Профили и адреса

Профиль — это способ замаскировать WireGuard от DPI провайдера: мусорные пакеты перед рукопожатием. Адрес WARP приложение выбирает само из пула адресов Cloudflare, текущий виден на странице «Профили».

- **Подобрать** — сначала все адреса текущего профиля, потом другие профили; сохраняет первую рабочую пару.
- **Выбрать лучший** — у каждого профиля ищет рабочий адрес и выбирает лучший по истории.

**Сам менять профиль** (Настройки → Подключение, включено по умолчанию): если WARP перестал отвечать, приложение само найдёт другой адрес или профиль и переподключится. VPN при этом не выключается.

## Работа в фоне

Чтобы система не закрывала VPN:

- **Настройки → Работа в фоне → Снять ограничение** — исключение из экономии батареи.
- На Xiaomi/Redmi/POCO там же кнопка **Автозапуск**, а в настройках приложения → «Контроль активности» выберите «Нет ограничений». Карточку приложения в недавних можно закрепить замком.
- Надёжнее всего — **Постоянная VPN** (Always-on): Настройки → **Системные настройки VPN** → WARP Unblock. Тогда Android сам поднимет VPN, если что-то его закроет. «Блокировать соединения без VPN» — системный kill switch, но с ним приложения, исключённые из VPN, остаются без сети.

## Списки и приложения

**Списки** — «Через WARP» и «Напрямую». Отключитесь, сохраните, подключитесь снова. «Напрямую» важнее правил WARP.

```text
# Только этот домен
example.com

# Домен со всеми поддоменами
+.example.org
```

**Настройки → Приложения в VPN** — все приложения, только выбранные или все, кроме выбранных. Применяется при следующем подключении.

Можно включить подключение при открытии приложения и после загрузки телефона. В шторку можно добавить плитку **WARP**.

## Если не проходит регистрация WARP

Приложение пробует зарегистрироваться напрямую, затем через встроенный обход DPI (ByeDPI, только для регистрации). Если не вышло — перенесите профиль с компьютера:

- **QR:** в Windows-версии — **Настройки → QR для телефона**, здесь — **Профили → QR**.
- **Файл:** `wgcf-profile.conf` из Windows-версии — **Профили → Файл**.

В профиле приватный ключ. Один ключ не стоит использовать одновременно на двух устройствах.

## Если не работает

| Что видно | Что сделать |
| --- | --- |
| WARP не отвечает | Выключить другой VPN, **Профили → Подобрать** |
| «Подключено», но ничего не грузится / «Порт занят» | Закрыть FlClash или другой клиент на ядре Clash |
| VPN пропадает при выключенном экране | См. «Работа в фоне» выше |
| Сайт не открывается | Добавить его домен в «Через WARP» |

**Журнал → Поделиться журналом** и [issue](https://github.com/kwlnd/warp-unblock/issues/new) с версией, профилем, моделью телефона, версией Android и оператором. В журнале могут быть домены и IP; профиль WARP и QR не публикуйте.

**Обновления:** при запуске приложение проверяет новые версии, скачивает подходящий APK, сверяет SHA-256 и открывает системный установщик. Ставится поверх, данные сохраняются.
