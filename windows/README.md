# WARP Unblock для Windows

Портативная программа для Windows 10/11 x64. Заблокированные сервисы идут через Cloudflare WARP, нейросети — через Opera EU поверх WARP, остальной интернет — напрямую.

**[Скачать последнюю версию](https://github.com/kwlnd/warp-unblock/releases/latest)** — файл `WarpUnblock-…-win-x64.zip`.

## Установка

1. Распакуйте архив целиком в отдельную папку с правом записи, например `D:\WarpUnblock`. Папка `app` должна лежать рядом с `WarpUnblock.exe`.
2. Запустите `WarpUnblock.exe` и разрешите права администратора — они нужны для TUN.
3. Если включён другой VPN (особенно FlClash, Clash Verge и другие клиенты на ядре Clash), выключите его.
4. Нажмите большую кнопку на главном экране. При первом запуске программа сама создаст аккаунт WARP.

Если WARP не отвечает, откройте **Профили WARP → Подобрать автоматически** и подключитесь снова.

Слева — разделы **Связь**, **Профили**, **Списки**, **Настройки** и **Журнал**. Цвет значка в шапке и в трее показывает состояние: серый — выключено, жёлтый — подключение, оранжевый — работает, красный — ошибка.

## Профили и адреса

Профиль — это способ замаскировать WireGuard от DPI провайдера: мусорные пакеты перед рукопожатием и, у части профилей, приёмы zapret. Адрес WARP программа выбирает сама из пула адресов Cloudflare.

- **Подобрать автоматически** — сначала пробует все адреса текущего профиля, потом другие профили, и сохраняет первую рабочую пару.
- **Выбрать лучший** — у каждого профиля ищет рабочий адрес и выбирает лучший по истории подключений.
- **Тест профиля** — проверяет выбранный профиль на текущем адресе.

Проверки идут без включения TUN, ваш интернет при этом не трогается.

**Сам менять профиль** (Настройки, включено по умолчанию): если WARP два раза подряд не ответил, программа сама найдёт другой адрес или профиль и переподключится. Свои аргументы winws она не трогает.

## Списки доменов

Раздел **Списки**, три вкладки:

| Вкладка | Что делает |
| --- | --- |
| Через WARP | Домены, которые нужно открывать через WARP |
| Напрямую | Домены, которые всегда идут напрямую; важнее правил WARP и Opera |
| AI через Opera | Домены нейросетей для Opera EU |

Отключитесь, внесите изменения, нажмите **Сохранить все списки** — правила применятся при следующем подключении.

```text
# Только этот домен
example.com

# Домен со всеми поддоменами
+.example.org
```

Один домен на строку, без `https://`, IP-адресов и путей. Международные домены — в punycode.

## Трей, автозапуск, обновления

Крестик сворачивает окно в трей (это меняется в настройках). Левый клик по значку открывает окно, правый — меню. Полностью закрыть программу — **Выход** в меню трея.

**Запуск вместе с Windows** (Настройки) стартует программу скрыто, в трее, и сразу подключается.

**Обновления.** Программа проверяет новые версии при запуске. В окне «Доступна версия» нажмите **Обновить**: соединение отключится, архив скачается и сверится по SHA-256, файлы заменятся, программа перезапустится. Аккаунт, настройки, журналы и ваши списки не трогаются. При ошибке старые файлы возвращаются на место.

**Резервная копия.** В настройках есть экспорт и импорт настроек вместе с аккаунтом, а также **QR для телефона** — перенос профиля WARP в Android-версию. В копии и QR лежит приватный ключ: не публикуйте их и не используйте один ключ одновременно на двух устройствах.

## Если не работает

| Что видно | Что сделать |
| --- | --- |
| WARP не отвечает | Выключить другой VPN, нажать **Подобрать автоматически** |
| «Порт занят» при подключении | Закрыть другой клиент на ядре Clash (FlClash, Clash Verge и т.п.) |
| Не проходит регистрация аккаунта | Посмотреть журнал; повторить позже или импортировать резервную копию |
| WARP работает, нейросети — нет | Посмотреть `opera-proxy.log` |
| Статусы зелёные, но сайт не открывается | Добавить его домен в «Через WARP»; проверить, нет ли его в «Напрямую» |
| Окно пропало после крестика | Открыть через значок в трее |

Журналы — в разделе **Журнал** и в папке `data/logs/`: `launcher.log`, `mihomo.log`, `zapret.log`, `opera-proxy.log`. В них могут быть домены и IP. Папку `data/warp/`, файл `data/mihomo/warp.yaml`, резервную копию и QR не публикуйте — там ключи.

[Сообщить о проблеме](https://github.com/kwlnd/warp-unblock/issues/new): укажите версию, профиль, провайдера и текст ошибки.
