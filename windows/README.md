# WARP Unblock для Windows

Портативный клиент Windows x64. Выбранные домены идут через WARP, AI-сервисы — через Opera EU поверх WARP, остальной трафик по умолчанию — напрямую.

**[Скачать Windows v0.7.2](https://github.com/kwlnd/warp-unblock/releases/tag/v0.7.2) · [Все релизы](https://github.com/kwlnd/warp-unblock/releases) · [Android](../android/README.md)**

## Установка и подключение

1. Скачайте `WarpUnblock-v0.7.2-win-x64.zip` со страницы релиза.
2. Распакуйте архив целиком в отдельную папку с доступом на запись. Папка `app` должна оставаться рядом с `WarpUnblock.exe`.
3. Запустите EXE и подтвердите права администратора.
4. Отключите TUN другого VPN-клиента, если он включён.
5. Нажмите **Подключить**. При первом запуске приложение создаст аккаунт WARP.

Если WARP не отвечает, откройте страницу **Профили WARP**, нажмите **Подобрать автоматически**, дождитесь результата и подключитесь снова. Тест и подбор идут без включения TUN; Opera проверяется при полном подключении.

Слева — разделы **Подключение**, **Профили WARP**, **Списки доменов**, **Настройки** и **Журнал**. Окно растягивается и разворачивается. Большая кнопка на главном экране подключает, отключает или отменяет текущую операцию.

## Списки проксирования

Откройте раздел **Списки доменов**. В нём три вкладки:

| Вкладка | Что делает |
| --- | --- |
| Через WARP | Добавляет домены для обхода через WARP |
| Напрямую | Направляет домены через DIRECT; имеет приоритет над доменными правилами WARP и Opera |
| AI через Opera | Добавляет AI-домены для HTTPS/TCP через Opera EU |

Отключите соединение, внесите изменения и нажмите **Сохранить все списки**. Правила применятся при следующем подключении.

```text
# Точный домен
example.com

# Домен вместе с поддоменами
+.example.org
```

Один домен на строку. URL с `https://`, IP-адреса и строки правил не подходят. Международные домены записываются в punycode. Редактор проверяет списки до записи.

Файлы: `app/config/lists/proxy-domains.txt`, `direct-domains.txt`, `ai-domains.txt`. Полное описание — [формат списков](https://github.com/kwlnd/warp-unblock/blob/main/docs/DOMAIN-LISTS.md).

## Профили и проверка сервисов

В каталоге 21 профиль доставки WireGuard к WARP. Они меняют способ установления тоннеля; выбирать отдельную стратегию для каждого сайта не нужно.

- **Тест профиля** проверяет выбранный профиль.
- **Подобрать автоматически** сохраняет первый рабочий.
- **Выбрать лучший** проверяет весь каталог и сравнивает успешность и задержку.

Ожидание ответа WARP ограничено **5 секундами на профиль**, включая запросы и повторы. Подготовка файлов и первая регистрация аккаунта выполняются отдельно. Дополнительной паузы между профилями нет.

Кнопкой **Проверить** в блоке «Проверка сервисов» на главном экране можно проверить HTTPS-доступность Discord, YouTube и Telegram через WARP. Зелёная отметка не подтверждает голос, просмотр видео или вход в аккаунт.

## Что известно о работоспособности

На 6 ноября 2026 года в локальных логах есть успешный запуск WARP и проверка выхода Opera EU. Прошли 12 unit-тестов, Clippy, release build и native self-test. Полный ручной прогон текущего релиза — Discord с голосом, YouTube, обычный интернет, трей и автозапуск — ещё требуется.

AI-трафик по правилам идёт через Opera EU, но доступность каждого AI-сервиса не подтверждена. Проверка Opera показывает доступность прокси и страну выхода, а не работу ChatGPT/Gemini/Claude целиком. Голосовые режимы AI и игровые сценарии отдельно не проверены.

Если Opera недоступна при подключении, запуск завершается ошибкой. Если она перестаёт работать позже, приложение сохраняет WARP и пытается восстановить Opera. Обычные запросы без правил обхода идут напрямую; в конфигурации также блокируются реклама и QUIC.

## Трей и автозапуск

Крестик по умолчанию скрывает окно в трей. Левый клик по иконке возвращает окно, правый открывает меню. Для завершения работы выберите **Выход**: приложение остановит свои процессы.

В настройках можно отключить сворачивание в трей и включить запуск вместе с Windows. Автозапуск создаётся задачей планировщика: приложение стартует скрытым и подключается. Служба не устанавливается.

## Обновление

Начиная с версии на GPUI, приложение само проверяет релизы при запуске (выключается в **Настройки → Обновления**). Если вышла новая версия, появится окно с описанием изменений и кнопками **Обновить**, **Позже**, **Пропустить версию**. По **Обновить** соединение отключается, архив скачивается и сверяется по SHA-256, файлы заменяются, программа перезапускается. Папка `data/` (аккаунт, настройки, логи) и три ваших списка доменов не трогаются. Если что-то пошло не так, старые файлы возвращаются на место.

Перейти с версий до GPUI (v0.5.1 и раньше) нужно вручную. Чтобы сохранить аккаунт и свои списки:

1. Отключите соединение в старой версии и выполните **Экспорт настроек и аккаунта**.
2. Если включён автозапуск, отключите его в старой версии. Закройте её через **Выход** в трее.
3. Распакуйте новый архив в отдельную папку и запустите приложение.
4. Выполните **Импорт копии** при отключённом соединении. При необходимости включите автозапуск в новой версии.

Экспорт содержит приватный ключ WARP. Предыдущие файлы при импорте сохраняются в `data/import-backups/`.

Для переноса профиля на телефон нажмите **QR для телефона**, а в Android откройте **Профили → Импортировать QR**. Один ключ нельзя использовать на двух устройствах одновременно.

## Если не работает

| Проблема | Что попробовать |
| --- | --- |
| WARP не отвечает | Отключить другой VPN, выполнить автоподбор или выбрать другой профиль |
| Ошибка регистрации аккаунта | Посмотреть журнал регистрации; повторить с другим профилем |
| WARP работает, Opera — нет | Посмотреть `opera-proxy.log`; доступ к AI через Opera проверяется отдельно |
| Зелёные статусы, но сервис не работает | Проверить его домены и список DIRECT; проверить сервис в самом приложении или браузере |
| Окно исчезло после нажатия крестика | Открыть приложение через иконку в трее |

Логи: `data/logs/`. Основные файлы — `launcher.log`, `mihomo.log`, `zapret.log`, `profile.log`, `opera-proxy.log`. Логи могут содержать домены и IP. Ключи в `data/warp/`, сгенерированный профиль `data/mihomo/warp.yaml`, резервную копию и QR публиковать нельзя.
