# SESSION — состояние и планы

Рабочая заметка проекта: что сделано, что не проверено, что планируется. Правила и устройство — в `DEVELOPMENT.md`.

## Opera proxy для AI
- Требуемая схема: только AI-домены направляются через локальный HTTP proxy Opera EU `127.0.0.1:1371`; обычный трафик остаётся DIRECT.
- `opera-proxy` v1.31.0 использует `-proxy http://127.0.0.1:17892` как базовый транспорт через принудительный WARP HTTP listener. Таким образом, соединение до Opera EU идёт в WARP, а AI-запрос выходит из Opera EU.
- Установщик закрепляет официальный бинарник `opera-proxy` v1.31.0. Самостоятельно собирается только winws. Не добавлять TCP zapret профили для Opera, не использовать Nova private relay credentials или DNS-AI.
- Startup/native health проверяют WARP через generate204, Opera через HTTPS trace и страну выхода; четвёртый статусный пункт — Нейросети. Локальный Opera listener сам по себе не подтверждает доступность AI-сервиса.
- Живое подключение этой схемы ещё не проверено. Автоматический review отклонил изолированный no-TUN запуск mihomo без указания причины; пока ограничиваться офлайн-проверками и не заявлять, что Opera/AI traffic реально работает.
- Для ручной проверки: подключить WARP и убедиться, что статусы WARP и Opera пройдены; проверить AI-сервис и обычный DIRECT-трафик; затем проверить отключение и остановку дочерних процессов.

## Текущее состояние

- **Windows** (ветка `main`, теги `v*`): приложение на Rust + egui, mihomo + winws, трей, автозапуск через планировщик, Ренат-мод, автоподбор профилей с прогрессом. Релизы собирает `.github/workflows/release.yml`.
- **Android** (ветка `android`, теги `android-v*`): Kotlin + Compose, VpnService, mihomo, hev-socks5-tunnel, регистрация WARP с обходом DPI через ByeDPI, импорт wgcf-профиля, плитка в шторке. Два APK: `arm64-v8a` и `armeabi-v7a`. Сборка — `.github/workflows/android.yml` (запускается из `main`, исходники берёт из ветки `android`).
- Проверено руками на телефоне: регистрация WARP через ByeDPI (стратегия `--fake -1 --ttl 8`), автоподбор, подключение, голос Discord, скорость обычного интернета.

## Не проверено вживую

- Windows: трей и скрытый старт, автозапуск через планировщик, Ренат-мод, полный TUN-тест, Discord (голос) и YouTube.
- Android: плитка в шторке на разных оболочках, поведение при агрессивной экономии батареи, длительная работа без разрывов.
