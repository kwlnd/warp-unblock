## Работа подключения
- По умолчанию DIRECT (в группе только DIRECT), WARP для явных правил; сохранять это решение пользователя.
- WARP внутри mihomo, аккаунт wgcf сохранён. AmneziaWG меняет только Jc/Jmin/Jmax (мусор до handshake), остальные поля WireGuard не меняются.
- 21 профиль предназначен только для доставки WireGuard к WARP: UDP-порт/эндпоинт/padding/UDP fake. Не добавлять пачки стратегий для Discord или YouTube — они уже идут внутри WARP.
- Автоподбор запускает свежий экземпляр mihomo без TUN на каждый профиль, останавливается на первом рабочем и сохраняет выбор/отчёт. Это проверка доступности, не тест качества голосовой связи.
- Winws ограничен IP WARP и выбранным UDP-портом. Только при первой регистрации используется отдельный TCP-процесс для API Cloudflare, затем он закрывается.
- Native launcher создаёт дочерние процессы suspended, включает их в Windows Job Object и только потом возобновляет. При закрытии/сбое приложение не оставляет свои процессы. Чужие VPN не убивает.
- API mihomo локальный: 9090, тест 9091; proxy 7890, тест 7891. SAFE_PATHS разрешает только app/config/lists. Несколько экземпляров с одним WARP-ключом не запускать.
