# SESSION — состояние и планы

Рабочая заметка проекта: что сделано, что не проверено, что планируется. Правила и устройство — в `DEVELOPMENT.md`.

## Текущее состояние

- **Windows** (ветка `main`, теги `v*`): приложение на Rust + egui, mihomo + winws, трей, автозапуск через планировщик, Ренат-мод, автоподбор профилей с прогрессом. Релизы собирает `.github/workflows/release.yml`.
- **Android** (ветка `android`, теги `android-v*`): Kotlin + Compose, VpnService, mihomo, hev-socks5-tunnel, регистрация WARP с обходом DPI через ByeDPI, импорт wgcf-профиля, плитка в шторке. Два APK: `arm64-v8a` и `armeabi-v7a`. Сборка — `.github/workflows/android.yml` (запускается из `main`, исходники берёт из ветки `android`).
- Проверено руками на телефоне: регистрация WARP через ByeDPI (стратегия `--fake -1 --ttl 8`), автоподбор, подключение, голос Discord, скорость обычного интернета.

## Не проверено вживую

- Windows: трей и скрытый старт, автозапуск через планировщик, Ренат-мод, полный TUN-тест, Discord (голос) и YouTube.
- Android: плитка в шторке на разных оболочках, поведение при агрессивной экономии батареи, длительная работа без разрывов.
