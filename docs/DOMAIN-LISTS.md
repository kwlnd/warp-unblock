# Общий формат списков доменов — v1

Windows и Android используют UTF-8 текстовые файлы `proxy-domains.txt` и `direct-domains.txt` (до 256 КиБ каждый). В Windows есть дополнительный `ai-domains.txt` для Opera; на Android AI остаётся внутри WARP.

- Один ASCII DNS-домен на строку. `example.com` — точное совпадение; `+.example.com` — домен и поддомены. `*.example.com` при сохранении превращается в `+.example.com`.
- Для зоны допустимо `+.ru`. Длина имени — до 253 символов, метки — от 1 до 63; дефис не может стоять первым или последним в метке.
- Редакторы убирают BOM, пробелы по краям, комментарии после `#`, пустые строки и дубликаты; переводят имена в нижний регистр и сортируют. Сохранение — LF, с переводом строки после последнего домена; пустой список — пустой файл.
- URL, порты, IP-адреса, строки правил mihomo и Unicode-домены отвергаются. Международные домены нужно записывать в punycode.
- Оба списка полностью проверяются до записи. Пользовательское DIRECT проверяется раньше WARP/Opera; защита локальной сети, блокировка рекламы и QUIC сохраняют более высокий приоритет.
- Изменения применяются при следующем подключении. Во время подключения редакторы заблокированы. Android сохраняет изменения в папке приложения; `Core.prepare()` больше не заменяет их заводскими файлами.

Проверки нормализации находятся в `source/src/features.rs` и Android `PortableSettingsTest.kt`. Статистика профилей имеет одинаковую JSON-схему на обеих платформах: индекс профиля → `attempts`, `successes`, `total_ms`. В рейтинг попадают только профили, успешно проверенные в текущем сравнении; сначала учитывается частота успеха, затем текущая задержка. Быстрый автоподбор по-прежнему останавливается на первом рабочем профиле.
