# WARP Unblock

Портативный Windows x64 клиент: mihomo держит WireGuard-тоннель WARP, нативное приложение на Rust + egui управляет подключением. Обычный трафик идёт через **DIRECT**; явные правила направляют AI-сервисы через локальный Opera proxy, а соединение с Opera proxy переносится через WARP.

## Установка

Скачайте архив `WarpUnblock-vX.Y.Z-win-x64.zip` из [Releases](../../releases), распакуйте в любую папку (не в Program Files) и запустите `WarpUnblock.exe`.

## Трей и автозапуск

В «Настройках» доступны тумблеры поведения приложения. **Запускать вместе с Windows** создаёт задачу планировщика «при входе» с правами администратора (без UAC-запроса): приложение стартует скрытым, в трее, и сразу подключается. **Крестик сворачивает в трей** включён по умолчанию; если выключить, крестик закрывает приложение (при активном подключении спросит). Иконка в трее: левый клик открывает окно, правый — меню (Открыть / Подключить / Отключить / Выход). Цвет иконки показывает состояние. Повторный запуск exe просто показывает уже работающее окно.

## Маршруты

Без селекторов и подгрупп: всё, что не попало в правила, идёт **DIRECT**; YouTube, Discord, Telegram, Spotify, мессенджеры, списки заблокированных — в **WARP**, а AI HTTPS — через **Opera EU поверх WARP**. Российские домены/адреса и локальная сеть — напрямую. Список в обход редактируется в `app/config/lists/proxy-domains.txt`.

## Запуск

Откройте **WarpUnblock.exe** из распакованного архива и разрешите права администратора. Отключите TUN других VPN-клиентов перед подключением.

- Нижняя кнопка **Подключить / Отключить** запускает и останавливает только свои процессы; во время операции она отменяет её.
- Сверху — состояние WARP и Opera. Проверка обновляется автоматически каждые 30 секунд.
- Раздел **Профиль WARP** раскрывает выбор, свои аргументы, **Тест профиля** и **Подобрать автоматически**. Тест и подбор проверяют только WARP без TUN; Opera проверяется при полном подключении.
- Раздел **Статус** показывает компоненты, профиль, WARP и страну выхода Opera EU.
- Раздел **Журнал** открывает события, логи и списки доменов.

Окно открывается размером 960×760; его можно растягивать и разворачивать. Кнопка подключения остаётся внизу. На главном экране есть кнопка «Редактировать списки проксирования»: она открывает отдельный редактор с вкладками WARP / DIRECT / Opera, большим полем и кнопкой сохранения. Размер редактора тоже меняется.
По умолчанию крестик скрывает окно в трей. Выход из приложения останавливает подключение; при аварийном завершении дочерние процессы завершаются Windows Job Object. Служба не устанавливается; автозапуск включается только тумблером в настройках.

## Дополнительные настройки

В **Настройки → Дополнительно** находятся проверка обновлений Windows по GitHub Releases, редактор трёх списков доменов, проверка Discord/YouTube/Telegram через WARP и экспорт/импорт резервной копии. Скачивание обновления открывается отдельно по ссылке «Релизы GitHub»; программа не заменяет работающий EXE автоматически.

Редактор проверяет списки перед записью. Пользовательский список «Напрямую» имеет приоритет над доменными маршрутами WARP и Opera. Изменения сохраняются при отключённом соединении и применяются при следующем подключении. Формат совместим с Android — см. [DOMAIN-LISTS.md](DOMAIN-LISTS.md).

Резервная копия JSON содержит настройки, списки и аккаунт WARP, включая приватный ключ. Храните её как пароль. Импорт выполняется при отключённом соединении; предыдущие файлы сохраняются в `data/import-backups/`. Настройка автозапуска остаётся локальной для этого компьютера. Кнопка **QR для телефона** показывает wgcf-профиль с reserved; на Android откройте **Профили → Импортировать QR**. Не подключайте два устройства с одним WARP-ключом одновременно.

**Проверить сервисы** проверяет HTTPS-доступность через принудительный WARP, независимо от обычных маршрутов. Зелёная отметка не подтверждает голос Discord, воспроизведение видео или работу аккаунта.

В **Профиль WARP → Выбрать лучший** проверяются все 21 профиль. Учитываются частота успеха и задержка; история находится в `data/profile-stats.json`. Обычный быстрый автоподбор по-прежнему останавливается на первом рабочем.

## AI-сервисы через Opera

Правила для AI-доменов направляют HTTPS/TCP на HTTP proxy Opera по `127.0.0.1:1371`. `opera-proxy` версии 1.31.0 открывает этот локальный порт и подключается к выбранному Opera EU серверу через WARP proxy `127.0.0.1:17892`. Поэтому внешний выход запросов к AI — Opera EU, а транспорт между компьютером и Opera proxy проходит внутри WARP. Остальной трафик остаётся DIRECT, если для него нет отдельного правила.

Для этой схемы zapret не добавляет TCP-стратегии: текущие WARP профили меняют только UDP доставку WireGuard. Установщик берёт закреплённый официальный бинарник `opera-proxy` v1.31.0; из исходников собирается только winws. Для SurfEasy API нужны публичные встроенные клиентские данные opera-proxy, приложение создаёт временную регистрацию устройства при запуске. Локальные или приватные relay credentials и DNS-AI не используются.

Проверка соединения проверяет WARP запросом generate204, а Opera — HTTPS trace с проверкой страны выхода. Запуск прекращается при недоступной Opera; если она падает после подключения, WARP остаётся работать, а приложение пытается восстановить Opera. Она не доказывает доступность каждого AI-сервиса и не проверяет качество приложения или аккаунта.

Opera поддерживает TCP CONNECT. UDP-трафик AI остаётся в WARP, UDP/443 блокируется для переключения на TCP. Голосовые режимы AI отдельно не проверены.

## Профили WARP

Каталог `app/config/strategies.json` содержит 21 профиль. Меняются только UDP-порт WARP, его эндпоинт, количество/размер мусорных пакетов перед handshake и UDP fake в winws. Готовых стратегий обхода отдельных сайтов здесь нет.

Профили — кандидаты, а не обещание работы у любого провайдера. Автоподбор проверяет HTTPS через тоннель на свежем экземпляре WireGuard; результат сохраняется в `data/strategy-results.json`. Перебор не измеряет качество голосовой связи, поэтому Discord-голос проверяется отдельно. Если WARP работает без zapret, его можно не запускать.

Только при первой регистрации аккаунта дополнительно применяется TCP-обход для API Cloudflare. Он завершается после регистрации и не перехватывает сайты.

## Диагностика

Логи находятся в `data/logs/`; их можно открыть из окна. Логи сохраняются после отключения. `launcher.log` — действия приложения, `mihomo.log` — подключения, `zapret.log` — winws, `profile.log` — подготовка WARP, `opera-proxy.log` — запуск Opera proxy. Если Opera status check не проходит, сначала убедитесь, что WARP поднят и Opera proxy слушает `127.0.0.1:1371`; затем отдельно проверьте, что правила отправляют AI-домен к этому proxy. Логи могут содержать домены и IP; ключи находятся в `data/warp/` и `data/mihomo/warp.yaml` — не публикуйте эти файлы.

## Сборка

Приложение: `powershell -NoProfile -ExecutionPolicy Bypass -File tools/build.ps1`. Нужны Rust 1.95 с rustfmt и MSVC Build Tools. Можно выбрать другую установленную версию через `-Toolchain`. Зависимости зафиксированы в Cargo.lock.

Только winws из исходников: `powershell -NoProfile -ExecutionPolicy Bypass -File tools/build-winws.ps1 -InstallToolchain`. Это скачает Cygwin/GCC внутрь `tools/.cache/`, без записи в реестр и ярлыков. Повторная сборка: та же команда без `-InstallToolchain`.

Код zapret закреплён на `v72.13`, commit `87e058624c72863db53bdaf7fb6f16576dddb6ab`. Код winws и ресурс manifest компилируются локально; готовые upstream `.o` ресурсы не используются. Библиотека импорта WinDivert остаётся из исходного дерева zapret. SHA-256 и версия GCC — в `app/bin/zapret/winws-build.json`. Вместе с winws копируется соответствующий runtime Cygwin. WinDivert.dll и подписанный драйвер WinDivert64.sys не пересобираются.
