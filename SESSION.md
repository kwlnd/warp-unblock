# SESSION — состояние и планы

Рабочая заметка: что сделано, что не проверено, что дальше. Устройство и сборка — [docs/DEVELOPMENT.md](docs/DEVELOPMENT.md).

## Структура и релизы

- Монорепо: только ветка `main`, папки `windows/` и `android/` (ветки `android`, `monorepo`, `ccr-*` удалены, PR #18 смержен).
- Релиз один на обе платформы: тег `vX.Y.Z` → `.github/workflows/release.yml` вызывает `windows.yml` и `android.yml`, публикует ZIP, два APK, `SHA256SUMS.txt` (и `.sha256` для ZIP — его читает апдейтер Windows). Версия общая; Android `versionCode` = major·10000+minor·100+patch (у android-v0.3.1 было 10).
- Выпущены: Windows v0.6.0 (отдельно, до объединения), общие v0.7.0, v0.7.1 (светящаяся сетка, AI-домены только через Opera) v0.7.2 (свечение, переходы, Android-паритет) и v0.7.3 (прокси с 7890 на 5630). «Что нового» дописано к обоим релизам вручную после CI (ренат мод не упомянут). Старые релизы не удалять — решение пользователя.
- Архив Windows: в корне `README.md` и папка `WarpUnblock/` (exe + `app/`, лицензии в `app/licenses/*.txt`). Пользователь просил не класть кучу .md.

## Windows (GPUI)

- `gpui-kit` 0.9.1, Rust ≥ 1.95 (`cargo +1.95.0`, `windows/tools/build.ps1` пинит). Своя плашка окна со статусом по центру (`WindowControlArea`), узкое меню слева с иконками Lucide, шрифт Manrope (вшит), светлая/тёмная тема (system/light/dark в настройках), круглая кнопка питания с метриками, всплывашки, подсказки на неактивных кнопках, анимации, иконка (`windows/tools/make-icons.py`).
- Обновление из программы (`update.rs`): окно → загрузка, SHA-256, замена через `*.old` с откатом, перезапуск `--after-update`. Живьём проверены загрузка+SHA+распаковка; полная установка с перезапуском — нет (нужен UAC).
- `--preview` пишет настройки в `windows/data/` (как обычный запуск); `WARP_PREVIEW_UPDATE=1` включает проверку обновлений в preview.

## Android

- Общий стиль с Windows: `Theme.kt` (палитра, Manrope), `Components.kt`, иконки Lucide (`android/tools/lucide-to-vector.py`), вкладки Связь/Профили/Списки/Настройки/Журнал, кнопка питания, иконка-щит.
- Апдейтер (`Updater.kt`, `UpdateUi.kt`) понимает общие `v*` и старые `android-v*`.
- Локальная сборка: `android/tools/build.ps1` (JDK 17, Gradle 8.9, SDK 34 в `android/.toolchain/`, в .gitignore; лицензия SDK принята с согласия пользователя). Снимки экранов: `-Tasks testDebugUnitTest,-Pscreenshots=1` → `android/app/build/screenshots/`. Нативных библиотек локально нет — рабочий APK собирает только CI.
- Проверено: 8 unit-тестов, lint, снимки экранов. На телефоне новый интерфейс и апдейтер не проверены.

## Главная карточка и Ренат мод

- `glow.rs`: свечение через размытые тени (`paint_drop_shadows`), золотой гребень волны, ореолы «звёзд», серая сетка при «отключено»; светлая тема — серая неподвижная сетка. Смена состояний — плавный переход (`glow::State`, 0,7 с). `.opacity()` у canvas и `paint_image` в GPUI прозрачность не учитывают — гасим вручную через `Frame::weight`, на время перехода сетка рисуется квадами. Рамка карточки рисуется второй раз поверх свечения.
- Блок прогресса фиксированной высоты (`PROGRESS_HEIGHT`), карточка не прыгает.
- Ренат мод (`mog.rs` + `c()` в `ui.rs`): полупрозрачный фон (видно фото), радуга, фото в кнопке и логотипе, «моггерские» надписи через `text()`/`button()`/подсказки/меню/плашку. Подключение — «могать», остановка — «эльдарнуться» (просьба Рената), «братик» вместо «брат/бро», «фрауд», «рейтнуть по PSL». Трей не переводим — решение пользователя.
- Preview: `WARP_PREVIEW_STATE=cycle` — состояния по кругу каждые 3 с.
- Android — то же: `GlowBackdrop`/`GlowGrid` в `Components.kt` (свечение радиальными градиентами, переход через `Crossfade` 0,7 с), высота подсказки (2 строки) и блока подбора фиксирована. Ренат мод: `Mog.kt` (словарь + обёртка `Text` в пакете перекрывает material3 — не импортировать `androidx.compose.material3.Text` явно), `renatPalette` в `Theme.kt`, фото в `res/drawable-nodpi/renat_*.jpg`, переключатель в «Настройках» → «Оформление». Проверено: unit-тесты, lint, снимки экранов (в т.ч. `home-renat`); на телефоне — нет.

## Решения

- Ренат мод — секретная пасхалка: в описаниях релизов, README и changelog о нём не писать.

## Открытые вопросы

- У друга пользователя подбор не нашёл ни одного из 23 профилей, в логах только таймаут ответа WARP; на старой версии с таймаутом 5 с — то же. Значит, не бюджет подбора. Нужны его `data/logs/launcher.log`, `mihomo.log`, `strategy-results.json`.

## Не проверено вживую

- Windows: пользователь проверил вживую (трей, подключение и прочее).
- Android: новый интерфейс на телефоне, выбор приложений, автозапуск, Always-on, QR-камера, отправка журнала, установка обновления.
- Автообновление обеих платформ заработает со следующего релиза после v0.7.0 (на v0.6.0/v0.7.0 переход с более старых — вручную).

## Гочи

- FlClash и другие клиенты Clash держат 127.0.0.1:7890 (у пользователя и на ПК, и на телефоне). mihomo при занятом mixed-port пишет ошибку и продолжает работать — API и проверка WARP проходят, а трафик TUN уходит в чужой прокси. Отсюда порты 5630/5631 и проверка портов перед стартом. Проверено на Xiaomi 12 Pro (Android 15) с запущенным FlClash: v0.7.3 грузит YouTube/Discord/Instagram.
- adb из Git Bash: `export MSYS_NO_PATHCONV=1`, иначе `/sdcard/...` превращается в путь Windows. adb лежит в `android/.toolchain/sdk/platform-tools/`.

- Зависший процесс preview `WarpUnblock.exe` (PID 4064) держал `windows/WarpUnblock.exe`; для тестов использовалось `windows/WarpUnblock-dev.exe` (все `windows/*.exe` в .gitignore).
- `sdkmanager.bat` режет аргументы по `;` — пакеты передавать через `--package_file`.
