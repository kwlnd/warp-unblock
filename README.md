# WARP Unblock

Клиент для Windows и Android, который направляет выбранные сайты и приложения через Cloudflare WARP. Остальной трафик по умолчанию идёт напрямую. В Windows для AI-сервисов используется Opera EU поверх WARP.

## Быстрый запуск

### Windows

1. Распакуйте архив целиком в отдельную папку, например `D:\WarpUnblock`. Оставьте папку `app` рядом с `WarpUnblock.exe`.
2. Запустите `WarpUnblock.exe` и подтвердите права администратора.
3. Отключите другой VPN, если он использует TUN.
4. Нажмите **Подключить**. При первом запуске приложение зарегистрирует аккаунт WARP.
5. Если WARP не отвечает, откройте **Профиль WARP → Подобрать автоматически**, затем подключитесь с найденным профилем.

Крестик по умолчанию сворачивает приложение в трей. Для полного закрытия выберите **Выход** в меню иконки. Окно можно растягивать и разворачивать.

### Android

1. Установите подходящий APK.
2. Откройте приложение, нажмите **Подключить** и разрешите создание VPN.
3. Если подключение не удалось, откройте **Профили → Подобрать автоматически**, дождитесь результата и подключитесь снова.
4. Если не проходит регистрация аккаунта, импортируйте wgcf-профиль файлом или QR из Windows-версии.

## Как идёт трафик

| Трафик | Windows | Android |
| --- | --- | --- |
| Обычные сайты, для которых нет правила | Напрямую — DIRECT | Напрямую — DIRECT |
| YouTube, Discord, Telegram и другие домены из правил обхода | WARP | WARP |
| AI-домены из правил | Opera EU, соединение до Opera идёт через WARP | WARP |
| Ваш список «Напрямую» | DIRECT с приоритетом над доменными правилами обхода | DIRECT с приоритетом над доменными правилами обхода |

В конфигурации также есть правила блокировки рекламы и QUIC. Доменные списки можно менять в интерфейсе. Windows: кнопка **Редактировать списки проксирования** на главном экране. Android: **Настройки → Домены**. Сохраняйте изменения при отключённом соединении; они применятся при следующем подключении.

Состояние на **6 ноября 2026 года**. Успешная сборка и зелёный статус соединения не означают, что проверены все сайты, приложения и провайдеры.

| Возможность | Статус |
| --- | --- |
| Android: регистрация WARP через ByeDPI, автоподбор и подключение | Проверено вручную на телефоне в базовом сценарии |
| Android: голос Discord и обычный интернет | Проверено вручную на телефоне; это не проверка всех устройств и операторов |
| Windows: запуск WARP и проверка выхода Opera EU | В локальных логах есть успешные проверки; полный прогон текущего релиза с Discord, YouTube и обычным интернетом ещё нужен |
| Доступ к каждому AI-сервису через Opera | Не подтверждён. Проверка страны выхода Opera не проверяет ChatGPT, Gemini или Claude целиком |
| Новые настройки Android: приложения в VPN, автозапуск, Always-on, камера QR, отправка журнала | Реализованы и собираются; практическая проверка на разных телефонах ещё нужна |

Заранее обещать работу у любого провайдера нельзя. Если конкретный сервис не работает, полезен отчёт с платформой, версией, выбранным профилем и текстом ошибки: **[создать issue](https://github.com/kwlnd/warp-unblock/issues/new)**.

## Полезные возможности

- **Быстрый автоподбор** останавливается на первом рабочем профиле. **Выбор лучшего** проверяет весь каталог и учитывает успешность и задержку.
- Ожидание ответа WARP — **до 5 секунд на профиль**, суммарно на запросы и повторы. Подготовка компонентов и первая регистрация аккаунта выполняются отдельно. Паузы между профилями убраны.
- Windows: редактор WARP / DIRECT / Opera, проверка HTTPS-доступности сервисов, резервная копия настроек и аккаунта, QR для телефона, трей и опциональный автозапуск.
- Android: маршрутизация по приложениям, редактор доменов, импорт профиля файлом или QR, плитка в шторке, отправка журнала, настройки автоподключения.
- На обеих платформах есть проверка обновлений со ссылкой на релизы. Установка новой версии выполняется вручную.

## Важные ограничения

- Opera используется только в Windows. Она передаёт TCP/HTTPS; голосовые и другие UDP-сценарии AI не подтверждены.
- Кнопка **Проверить сервисы** в Windows проверяет HTTPS через WARP. Она не проверяет голос Discord, воспроизведение видео или вход в аккаунт.
- В Android Always-on и блокировка соединений без VPN включаются в системных настройках. Системная блокировка может лишить сети приложения, исключённые из VPN.
- Автозапуск Android зависит от оболочки и ограничений батареи.
- Один WARP-ключ не следует использовать для одновременного подключения компьютера и телефона. Для каждого устройства лучше отдельный аккаунт.

## Обновление и диагностика

Перед обновлением Windows экспортируйте резервную копию, чтобы сохранить аккаунт, настройки и свои списки. Порядок переноса описан в [инструкции Windows](docs/README.md#обновление). Android APK можно установить поверх предыдущей версии.

В Windows журнал открывается из приложения; файлы находятся в `data/logs/`. В Android есть **Журнал → Поделиться журналом**. Логи могут содержать домены и IP. Резервная копия, wgcf-профиль и QR содержат приватный ключ — не прикладывайте их к публичным issue.
